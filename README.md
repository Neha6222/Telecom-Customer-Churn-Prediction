# 📊 Telecom Customer Churn Prediction & Power BI Dashboard

## 📌 Project Overview

This project predicts customer churn using Machine Learning and visualizes customer behavior through an interactive Power BI dashboard. The objective is to help businesses identify customers who are likely to churn and support customer retention strategies.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- Power BI
- GitHub

---

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier (Best Model)

### Best Model Performance

- **Model:** Random Forest
- **Accuracy:** **79.7%**

---

## 📊 Dashboard Features

- Total Customers
- Churn Customers
- Predicted Churn Customers
- Churn by Contract Type
- Churn by Internet Service
- Churn by Payment Method
- Average Monthly Charges by Churn
- Average Customer Tenure by Churn
- Interactive Slicers

---

## 💡 Key Business Insights

- Month-to-month customers have the highest churn.
- Fiber optic customers show the highest churn.
- Electronic check customers have the highest churn.
- Customers with shorter tenure are more likely to churn.
- Customers with higher monthly charges are more likely to churn.
