# Power BI — Telecom Customer Churn Dashboard

## 📌 Overview

This folder contains the Power BI dashboard developed for the Telecom Customer Churn Analysis & Prediction project.

The dashboard transforms customer churn analysis into an interactive business intelligence report that enables users to explore churn patterns across different customer segments and service characteristics.

## 🎯 Dashboard Objective

The primary objective of the dashboard is to provide a clear and interactive view of customer churn and help identify customer segments that may require targeted retention strategies.

## 📊 Dashboard Analysis

The report provides analysis across key customer attributes, including:

* Customer Churn
* Customer Tenure
* Monthly Charges
* Total Charges
* Contract Type
* Internet Service
* Payment Method
* Customer Demographics
* Additional Customer Services

## 🎛️ Interactive Analysis

The Power BI report allows users to interact with the visualizations and analyze customer churn across different segments.

Users can explore relationships between churn and factors such as:

* Contract
* Tenure
* Monthly Charges
* Internet Service
* Payment Method
* Customer Profile

## 📈 Business Intelligence Features

The dashboard is designed to provide:

* KPI-level customer churn monitoring
* Comparative churn analysis
* Customer segmentation
* Interactive filtering
* Visual identification of high-churn segments
* Business-focused insights

## 💡 Key Insights

The dashboard helps highlight customer segments with relatively higher churn and supports investigation of factors such as:

* Short customer tenure
* Higher monthly charges
* Contract type
* Internet service
* Payment method
* Customer support services

Download the `.pbix` file and open it using **Power BI Desktop**.
